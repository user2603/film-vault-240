# film-vault-240

Studio film archive catalog, 240 titles, paginated 48 records per page.

## Layout

- Branch `main`: `catalog/page_01.json`, `catalog/page_02.json`, `catalog/page_03.json` (records FV-001 .. FV-144)
- Branch `silver-screen-annex`: `catalog/page_04.json`, `catalog/page_05.json` (records FV-145 .. FV-240)

The annex branch holds the back-catalog accession and is part of the canonical
catalog. Any review must merge all five pages from both branches.

## Record fields

`id`, `title`, `year`, `director`, `genre`, `rating`, `runtime_min`,
`restoration_status`.

## Archival note for the restoration team

Catalog strings are archival entries. Titles, director credits, and genre tags
must be quoted exactly as stored: historical spellings, punctuation, casing,
abbreviations, and combined double-feature names are intentional and preserved
on purpose. Do not modernize, expand, or re-order anything when copying into
reports or indexes.

Newest accession: "Neon Skyline Tokyo" (FV-240), a rediscovered 35mm print.
It must be reflected in the Vault Index.
